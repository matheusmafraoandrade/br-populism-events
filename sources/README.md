# sources/

Put plain-text (`.txt`, UTF-8) versions of your source documents here, one per file, e.g. `s01_vdem_country_report.txt`.

Log every file in `../source_log.csv` (title, URL, access date, type, language).

Suggested mix (5 to 10 documents): open-access academic articles, country reports from organizations such as V-Dem or Freedom House, encyclopedia entries, and news articles. Check each source's terms before redistributing it; if in doubt, keep texts local and only commit the log.
